# 熱量手帳

記錄每天吃的食物、熱量、營養成分和喝水量的網頁 app，手機和電腦都能用。

**直接使用：** https://jerryyehyee.github.io/kcal-diary/

## 功能

- **每日熱量預算**：圓環顯示今天還能吃多少，吃超過會變紅色。
- **建議熱量計算**：輸入性別、年齡、身高、體重、目標體重和活動量，用 Mifflin-St Jeor 公式算出每日建議攝取量和預估達成日期。
  - 安全下限：每天最多比消耗少吃 25%，女性不低於 1200 kcal、男性不低於 1500 kcal。
- **營養成分**：蛋白質、脂肪、碳水化合物、糖、鈉，跟台灣營養標示的欄位一樣。
- **掃 QR code**：拍食物上的 QR code，第一次填好熱量後 app 會記住，下次掃同一個 code 就自動帶入。
- **喝水紀錄**：每日目標是體重 × 35 ml。
- **最近 7 天**的熱量長條圖。
- **匯出／匯入備份**。

## 資料存在哪裡

- **在 GitHub Pages 上使用**：資料只存在你自己的瀏覽器（localStorage），不會上傳到任何地方。換手機或清除瀏覽器資料前，請先匯出備份。
  - iPhone 建議用 Safari 的「加入主畫面」，資料比較不會被系統清掉。
- **在 Claude artifact 裡使用**：資料存在你 Claude 帳號的私人空間，換裝置也會同步。另外可以上傳營養標示或學校頁面的截圖，讓 Claude 自動讀出數值。

## 開發

`kcal-diary.html` 是原始檔，同時也是 Claude artifact 的內容。修改後執行下面的指令，產生給 GitHub Pages 用的 `index.html`：

```sh
./build.sh
```

QR code 辨識使用 [jsQR](https://github.com/cozmo/jsQR)。

> 熱量計算只是估算，不能取代醫師或營養師的建議。
